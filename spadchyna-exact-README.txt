Спадчына — точная копия сайта на HTML, CSS и JS.
Откройте index.html в браузере (нужен интернет для карты и шрифтов).
Каждая страница — отдельный .html файл, стили — styles.css, скрипты — app.js и data.js (места, вопросы, координаты), картинки — папка assets.
Работают: Яндекс Карта с метками, вопросы на страницах мест, окно входа (демо).
Не работают без сервера: настоящий вход, админ-панель, батлы по коду между устройствами.
